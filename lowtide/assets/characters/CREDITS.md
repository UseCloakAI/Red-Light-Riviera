# Character credits

- **michelle.glb**: "Michelle", a character from [Mixamo](https://www.mixamo.com) (Adobe), via the three.js examples. Slimmed for the web: the mesh is simplified and quantized, and the textures are WebP.
- **anims.json**: idle, walk and run from Mixamo (via the three.js `Xbot` example), retargeted onto Michelle's rig with `tools/retarget`.
